# CRC 三方协议审核（申办方视角）

收到合同文本后，严格执行以下五段流程。禁止跳段、禁止只做关键词匹配、禁止省略报告章节。

## 必读文件

- 规则库：[references/crc-rules-sponsor.md](references/crc-rules-sponsor.md) — 23 条规则（红 10 / 黄 11 / 蓝 2）+ 全局审核基准。审核前完整读入；每条规则的风险说明、合规依据、整改建议、替换条款**原文取用，不改写**。
- 报告模板：[references/report-template.md](references/report-template.md) — 输出格式定稿，逐章渲染。

## 输入处理

- **用户粘贴纯文本** → 直接进入第 0 段。
- **用户上传 .docx 文件** → 先运行提取脚本，再进入第 0 段：
  `python3 scripts/extract_docx.py <合同.docx> <提取结果.txt>`
  脚本仅依赖标准库，保留段落与表格顺序。提取后向用户确认字符量合理（过短提示可能提取失败），再开始审核。
- **用户上传 .pdf 或其他格式** → 提示用户先转贴文本或转 .docx，MVP 不处理。

## 第 0 段：输入预处理

通读全文，识别章节与条款结构，为每个条款建立定位锚点（章节号·条款号；无编号的按"第 N 段"编号）。文本 < 500 字或明显非 CRC 三方协议时，先向用户确认，不强行审核。

## 第 1 段：全文基准校验

按规则库"全局审核基准"A~D 校验：

- A. 核心权责逻辑（医学决策归 PI / 事务执行归 CRC / 管理追责归 SMO / 监督权归申办方）——作为后续所有条款判断的解释准绳。
- B. CRC 合规三要素（机构许可、PI 书面授权、职权边界）——逐一确认全文是否有落点，结果写入报告第二章。
- C. 合法工作范围白名单——标记白名单外的工作内容描述，供 RED-001/002/003 重点核查。
- D. 法律关系适配——非"SMO 外派 CRC"三方关系的，判"条款适配瑕疵"，在报告中显著警告，仍继续审核。

## 第 2 段：存在型规则扫描（9 条）

对每条存在型规则（RED-001~006、008、010、011，其中 RED-005、008、011 为双态规则的存在态），逐条款做语义判断：

- 判断单元是"条款在说什么"，不是关键词。`定位线索`仅用于快速定位，不构成命中依据。
- 防漏报：条款表述与规则的`同义变体示例`语义等价即列为候选命中，不要求字面相似。
- 候选命中记录：规则 ID、定位锚点、原文摘录、命中理由（一句话）。
- 同一条规则多处命中时合并为一条风险、列出全部定位。

## 第 3 段：缺失型规则兜底（13 条）

对每条缺失型规则（RED-007、009、013~018、022、023、024、025、026，及 RED-005、008、011 缺失态），通读全文逐条出具三选一结论：`已具备`（附定位证据）/ `约定不足`（附缺口说明）/ `缺失`。

- 以规则的合规写法示例做**反向确认**：找到语义等价的实质约定才算"已具备"。
- 提及 ≠ 承诺：鉴于条款/定义部分提到法规但未形成义务条款的，仍判缺失。
- 约定分散在不同章节但合计覆盖的，判"已具备"。
- `约定不足`与`缺失`进入候选命中清单。每条缺失型规则必须在报告第七章核对表留下结论，禁止"没扫到就跳过"。

## 第 4 段：双重核对（防误报）

对第 2、3 段全部候选命中逐条执行，顺序不可颠倒：

1. **触发条件复核**：重读原文所在条款完整语境（含前后条款），确认语义确实满足`语义触发条件`；不满足则撤销，记录原因。
2. **误报豁免核对**：对照该规则`误报豁免`逐情形检查；落入豁免则撤销。**冲突时以豁免为准。**

定级以规则库等级字段为准，不得自行升降级；RED-005、RED-008、RED-011 双态命中时各自合并为一条风险输出，RED-005 存在态命中按 🔴、缺失态命中按 🟡，双态同时命中合并并按 🔴 输出。

## 第 5 段：报告输出

- 严格按报告模板九章渲染。风险卡片字段全部来自规则库条目原文；替换条款中`【 】`占位符保留原样。
- 零风险时仍输出完整报告（全局校验 + 核对表 + "未发现风险"结论），禁止只回一句"没问题"。
- 报告为最终交付物，直接作为回复正文输出；用户要求存档时另存为 `审核报告_YYYYMMDD_HHMMSS.md`。

## 铁律

1. 语义优先：每条命中必须能回答"这句话到底在说什么"，回答不出就撤销。
2. 每条命中必须四要素齐备：原文定位摘录、风险定级与依据、整改建议、可粘贴替换条款。
3. 缺失型规则全部留核对痕迹——这是旧版漏报的主因，不可退化。
