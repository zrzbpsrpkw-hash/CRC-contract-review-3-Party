# CRC 三方协议审核工具（申办方视角）

> 临床试验 CRC 三方协议（申办方-研究机构-SMO/服务方）合规审核工具集：AI Skill 语义审核版 + 纯前端关键词初筛版。帮助法务/合规人员识别合同风险、输出红黄蓝分级报告与可直接粘贴的替换条款。

**当前版本 v2.0**：规则库 23 条（🔴 红 10 / 🟡 黄 11 / 🔵 蓝 2），AI Skill 与前端工具共用同一套规则。

## 📋 规则体系（v2.0）

- 🔴 **红色（10 条，整改前禁止签署）**：CRC 医学判断/医疗操作/无限兜底（RED-001~003）、数据与知识产权归属（004）、责任免除与人事责任穿透（005，双态分级）、转包分包（006）、PI 书面授权（007）、单方更换权（008，双态）、数据合规专项（009）、人员审核否决权（021）
- 🟡 **黄色（11 条，签署前必须优化）**：费用支付风控-两方协议/里程碑双情形（010）、变更控制（011，双态）、保密（013）、反商业贿赂（014）、GCP 合规承诺（015）、交接标准（017）、违约责任完整性（018）、数据移交（022）、人员稳定性（023）、重大事件报告（024）、申办方终止权（026）
- 🔵 **蓝色（2 条，建议优化）**：鉴于条款与项目依据（016）、争议解决（025）

双态规则（005/008/011）同时支持"存在型"（有问题条款）与"缺失型"（无约定）两种检查形态，双态命中合并输出；RED-005 按状态分级（存在态 🔴 / 缺失态 🟡）。

## 📄 审核依据

《药物临床试验质量管理规范（GCP）》、《临床研究协调员实践和管理专家共识（2024版）》、《药物临床试验CRC管理·广东共识（2024年版）》、《数据安全法》、《个人信息保护法》、《人类遗传资源管理条例》、《执业医师法》、《民法典》、《反不正当竞争法》、《劳动合同法》、《仲裁法》、《民事诉讼法》及增值税发票管理相关规定、行业惯例。
