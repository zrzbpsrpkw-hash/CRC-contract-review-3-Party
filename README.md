# CRC三方协议智能审核系统

> 一个基于浏览器运行的临床试验 CRC 三方协议合规审核工具，帮助法务/合规人员快速识别合同风险并提供修改建议。

## 🔗 在线使用

直接打开浏览器访问以下链接即可使用，无需安装任何软件：

**👉 [点击在线使用](https://你的用户名.github.io/crc-contract-auditor/)**

（请将 `你的用户名` 替换为您的 GitHub 用户名）

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| **24条专业审核规则** | 覆盖 CRC 职权越权、数据权属、合规风控、条款完整性等 6 大类别 |
| **三级风险分级** | 🔴 红色风险（强制拦截）/ 🟡 黄色风险（必须整改）/ 🔵 蓝色瑕疵（建议优化） |
| **合同角色配置** | 自动提取甲方/乙方/丙方，映射到申办方/研究机构/服务方 |
| **双版本输出** | 标准版（专业术语） ↔ 合同适配版（甲方/乙方/丙方） |
| **红色风险聚合** | 同一风险编号的多处触发点聚合为一张卡片，避免重复阅读 |
| **上下文高亮** | 自动提取触发词前后上下文，精确定位风险位置 |
| **报告导出** | 支持导出 Markdown 格式的完整审核报告 |
| **纯前端运行** | 合同文本仅在本地浏览器处理，不上传任何服务器，数据安全 |

## 🚀 快速开始

### 方式一：在线使用（推荐）

直接在浏览器中打开项目主页即可使用，无需安装。

### 方式二：本地使用

1. 下载本仓库的 `index.html` 文件
2. 双击用浏览器打开
3. 粘贴合同文本，点击「开始审核」

### 方式三：加载示例快速体验

1. 打开工具页面
2. 点击右上角「加载示例」按钮
3. 系统会自动填入示例合同文本和角色配置
4. 点击「开始审核」查看效果

## 📖 使用指南

### 第一步：粘贴合同文本

将 CRC 三方协议的完整文本粘贴到输入框中。

### 第二步：配置合同角色（可选但推荐）

点击「⚙️ 合同角色配置」展开面板：
- 点击「从合同文本自动提取」按钮，系统会尝试提取甲方/乙方/丙方名称
- 为每一方选择对应的系统角色（申办方 / 研究机构 / 服务方）
- 核对映射预览是否正确

### 第三步：开始审核

点击「开始审核」按钮，等待系统分析完成。

### 第四步：查看结果

- 查看统计概览，了解整体风险等级
- 切换红色风险 / 黄色风险 / 蓝色瑕疵标签页查看详情
- 切换「标准版」或「合同适配版」查看不同格式的建议条款
- 点击「导出 Markdown」下载完整审核报告
